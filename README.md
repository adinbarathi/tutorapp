# Aether Tutor

A premium, interactive, and responsive single-page Tutor web application with dynamic course/content updates for tutors and interactive study tools for learners.

## Features

- **Dashboard**: Track your study streak, total duration, and dynamic course completion progress bars.
- **AI Tutor Aura**: Chat with an educational assistant that answers science, history, and coding inquiries with visual formatting, formatting codes, and typing indicators.
- **Curriculum Explorer**: Navigate courses and study modules. Includes a **Flexbox Sandbox** visualizer for layout alignment.
- **3D Flashcards**: Study custom decks, click to flip cards on a 3D axis, and record recall scores.
- **Quiz Studio**: Test knowledge, review detailed question explanations, and see a confetti burst on getting a perfect score.
- **Pomodoro Timer**: SVG circular countdown focus clock with study/break mode presets and relaxing ambient background sounds.
- **Tutor Console**: Add new courses, create flashcards, and design custom quiz questions. Automatically persists to `localStorage`.

## Tech Stack
- HTML5 (Semantic elements)
- CSS3 (Vanilla design tokens, custom variables, animations, 3D transforms)
- Vanilla JS (Local storage bridging, SVG dynamic progress rendering, Web Audio synthesis, Canvas particles)

## Run Locally
1. Clone this repository.
2. Double-click `index.html` to run in any browser.
